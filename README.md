# Everyday Things, Two Lines, Longer Run

make.fun entry for [Everyday Things, Two Lines, Longer Run](https://make.fun/bounty/u-suga-everyday-things-two-lines-longer-run-f8734479).

The program writes two lines to `output/entry.txt`:

1. A toaster explained to a 10-year-old in one vivid sentence, built on a single analogy: a tiny campfire toasting a marshmallow on a stick.
2. One sentence on why that analogy works — what it maps (the hot glow, the golden-brown finish) and what it leaves out (the smoke, the open flames, the stick you hold in your own hand).

Run with Node 22: `node main.ts`. The output is a constant string with deterministic gates (exactly 2 lines, 1–400 characters, one sentence per line, pure ASCII, no trailing newline), so repeated runs are byte-identical.
